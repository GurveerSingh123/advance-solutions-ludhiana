# Advance Solutions — Ludhiana

One-page business website for **Advance Solutions**, a mechanical engineering and
manufacturing workshop in Ludhiana, Punjab specialising in CAD/CAM, VMC/CNC
machining and custom component manufacturing.

**Live:** https://advance-solutions-ludhiana.vercel.app

## Tech stack

| | |
|---|---|
| Framework | React 18 + TypeScript |
| Build | Vite 6 |
| Styling | Tailwind CSS v4 (`@tailwindcss/vite`) |
| Icons | lucide-react |
| Hosting | Vercel (auto-deploys from `main`) |

No backend — it is a static marketing site.

## Getting started

```bash
npm install
npm run dev      # dev server on http://localhost:5173
npm run build    # type-check (tsc -b) + production build to dist/
npm run preview  # serve the production build locally
```

## Project layout

```
src/
  components/       one component per page section
    ui/             Logo, Section, Button primitives
  hooks/            useReveal (scroll-reveal)
  lib/business.ts   all contact details, in one place
scripts/            one-off asset generators (not part of the build)
```

### Editing contact details

Phone, WhatsApp, email and address all come from
[`src/lib/business.ts`](src/lib/business.ts). Change them there and every
button, link and the structured data update together.

## Assets

Two committed assets are generated by scripts and are **not** rebuilt during
`npm run build`. Re-run them only when the source artwork changes:

```bash
# Re-trace the logo from the owner's artwork.
# Also rewrites public/favicon.svg and the mark inside scripts/og-image.svg.
npm i -D sharp potrace && node scripts/trace-logo.mjs <source-image> && npm un sharp potrace

# Re-render the 1200x630 social preview card from scripts/og-image.svg.
npm i -D sharp && node scripts/make-og.mjs && npm un sharp
```

The traced logo path lives in
[`src/components/ui/logoPath.ts`](src/components/ui/logoPath.ts) and is filled
with `currentColor`, so it takes the theme gold.

## Deployment

Pushes to `main` deploy to production automatically via the Vercel Git
integration. To deploy manually:

```bash
npx vercel deploy --prod
```

## Content policy

The copy deliberately avoids claims the business has not substantiated — no
ISO certification, guaranteed tolerances, production capacity, years of
experience, testimonials or statistics. Keep it that way unless there is
something real to back a claim up.
